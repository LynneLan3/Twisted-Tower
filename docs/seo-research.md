Branch: `feat/twisted-tower-site-v1`## What is this game?

Twisted Tower is a single-player first-person action-adventure horror shooter set in an
abandoned 1950s theme park / resort. The player climbs a tower made of themed floors,
fighting corrupted fairy-tale mascots, solving environmental puzzles, and uncovering a
story tied to the player character's past in order to rescue the love interest at the top.

- Developer: Atmos Games (indie studio led by Thomas Brush, creator of Pinstripe and Neversong)
- Publisher: 3D Realms (a Saber Interactive publishing label)
- Release: 2026-08-18 on Steam (PC / Windows only)
- Price: $14.99; 10% launch discount ($13.49) until 2026-09-01
- Reviews at research time: Overwhelmingly Positive (95% of 779 reviews)
- Genre tags on Steam: Action, Adventure, Indie

## Low-confidence or intentionally omitted content

- **Specific enemy names** (e.g., "Clown Scouts", "Balloon Dogs") — found only in
  unverified pre-release third-party guides; not used as facts.
- **Final boss / ending details** ("Mr. Twister", alternate endings) — only from
  pre-launch gameplay recordings and unverified walkthroughs; not used in MVP.
- **Park backstory characters** (e.g., "Mr. Jollibee") — only from an unverified
  third-party guide; not used.
- **Per-level weapon placement** — third-party only; official sources do not specify
  which weapon is found on which floor. MVP page lists the official weapon set without
  floor mapping.
- **Collectible taxonomy** ("Memo Pages", "Map Fragments", "Twisted Tokens", audio
  recordings) — unverified as exact named systems; omitted from MVP. Only "secret
  areas" and "tickets" are confirmed via official achievements.
- **Exact puzzle solutions / step-by-step walkthrough** — not confirmed against the
  retail build; deferred until verified post-launch content is available.
- **Console versions** — not announced; only covered as "PC-only, no console announced".
- **DLC** — none announced; not covered.

## MVP page selection rationale

MVP = 1 hub + 8 guides across 5 categories. Every page answers a real post-launch
player question and every fact traces to an official or reliable-review source.
No page was created merely to fill a template slot (e.g., no "best weapons" tier list,
no "all bosses", no "all collectibles" without evidence).

## V2 content-fill round (2026-08-21, post-launch)

The 8 MVP guide pages were expanded from skeletons to full player-facing content.
Sources evaluated this round:

### Accepted as facts
- Steam store page (weapons list, five floors, system requirements, release info, toys for jumping/dashing/grappling).
- Steam Community official achievements (18 achievements, four named movement toys, Tickets, Adventure Plus).
- 3D Realms launch announcement via Gematsu (five levels).
- Kotaku, COGconnected, NoobFeed launch reviews (length 4–6h, Vincent/Charlotte story, upgrades at stations, alt-fires, Adventure Plus carries upgrades and opens routes).
- WayTooManyGames launch review (enemy variety: corrupted mascots, clowns with running makeup, "mermaids", fairy godmothers, UFO-piloting aliens; 1950s soundtrack).
- PlayFront (PC-only; no console announced).

### Accepted only as clearly-labeled community walkthrough tips (not facts)
- 9Puz walkthrough (2026-08-19, claims a verified 3:49:28 start-to-credits recording that could not be independently verified):
  - Progress-check method (keys/attraction completion/save messages/elevator readback).
  - Named floor anchors: Clock Tower transition, Thundertracks + Footmother Maze in Carnival Forest, Goldfish-marked area in Space Station.
  - Final boss name "Mr. Twister" (multiple third-party guides agree, but no official/review source names it; page wording keeps it generic).
  - First-day build 1.0.3 and an upcoming 1.0.4 (from the developer's first-day Steam announcement, relayed by 9Puz).
  - Page wording for these is labeled as community-sourced and linked to the editorial-method page.

### Rejected this round (not usable as facts)
- Game How To guide — pre-release content (last checked 2026-08-09, page updated July 2026);
  its system requirements contradict the official Steam page (Win7 / 2GB / DX9 vs Win10 / 8GB / DX11);
  specific enemy/boss names (Clown Scouts, Balloon Dogs, Ringmaster) and Mr. Jollibee backstory unverified.
- Worldeka — weapon-floor mapping conflicts with Game How To; names not corroborated.
- 2UpSkill — invents a "Pure Heart" achievement and a "Secret Boss"; official achievement list has no such entries. Confirms SEO guide sites fabricate content.

### Still intentionally omitted

- The final boss is referenced generically; the name "Mr. Twister" is treated as community-reported, not official.
