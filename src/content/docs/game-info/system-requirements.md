The official minimum and recommended specifications published on the Twisted Tower Steam store page are below. This page helps you judge whether your PC can run the game, plus how to approach common performance issues.

## Minimum requirements

- Requires a 64-bit processor and operating system
- OS: Windows 10 64-bit
- Processor: Intel i5-6600 / AMD Ryzen 5 1600X
- Memory: 8 GB RAM
- Graphics: GTX 670 / RX 570 / Arc B580
- DirectX: Version 11
- Storage: 8 GB available space

## Recommended requirements

- Requires a 64-bit processor and operating system
- OS: Windows 11
- Processor: Intel i5-8400 / AMD R5 2600
- Memory: 16 GB RAM
- Graphics: GTX 1660 / Vega FE
- DirectX: Version 11
- Storage: 8 GB available space

## How to judge your own PC

- **RAM is the most common gate**: the minimum is 8 GB. Below that, even a capable GPU can hit stutter.
- **GPU**: the minimum tier (GTX 670 / RX 570 / Arc B580) is the entry line; the official recommendation is GTX 1660 / Vega FE.
- **OS**: the minimum is Windows 10 64-bit, with Windows 11 recommended. The game is currently Windows-only — no macOS or console version has been announced.

## Notes on performance

- Around launch, there were community discussions about performance and stutter; the developer pinned performance and fix threads on Steam Community (source: Steam Community, from 2026-08-19).
- The post-launch build is still being updated (the developer's day-one announcement described the current build as 1.0.3 and promised follow-up patches). If you hit an anomaly, first check for game updates and the official pinned threads (source: official day-one announcement, relayed by community run records).
